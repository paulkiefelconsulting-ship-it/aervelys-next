# AERVELYS NEXT

Eigenständiger Next.js-Prototyp für das Airline Command Center. Nicht mit AERVELYS OPS verbunden.

## Lokal starten

```bash
npm install
npm run dev
```

**Status:** Entwicklungs-Demo mit statischen Daten, ohne Live-Zugriff auf Supabase, ohne operative Flugfreigaben. Vor einer Veröffentlichung sind Anmeldung, Rechteprüfung und Deployment-Schutz erforderlich.

Hostingziel: Vercel. Backend: separates Supabase-Projekt für AERVELYS NEXT.
