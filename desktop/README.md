# AERVELYS NEXT Desktop · Windows Alpha 0.1

This is original AERVELYS NEXT code, inspired by aviation simulation workflows but not copied from SkyBridge OPS binaries, source, artwork or assets.

## Alpha installer

- Genuine installable Windows x64 app (Electron / Chromium with NSIS setup)
- Existing AERVELYS NEXT Airline Command Center in dedicated desktop window
- Existing Supabase/CEO login and cloud airline data with persistent desktop browser session
- AERVELYS-brand navy/silver/blue icon and offline recovery screen
- Native refresh, fullscreen, zoom and allowlisted external links
- Security: only NEXT HTTPS origin renders inside the app; Node.js renderer integration disabled, context isolation and sandbox enabled, webview denied, permissions restricted
- Unsigned Windows installer artifact generated by GitHub Actions

NOT INCLUDED YET: bundled MSFS SimConnect engine, full offline simulation, automatic updates, verified live flights or synchronized local cache. The current C# SimConnect prototype is still a separate process and has not passed a full Windows/MSFS end-to-end test. The first Desktop build requires internet access to reach Vercel and Supabase.

## Download the installer from GitHub Actions

1. Visit GitHub -> Actions -> AERVELYS NEXT Windows Desktop.
2. Open a successful run.
3. Download the artifact named AERVELYS-NEXT-Windows-Setup (GitHub sign-in may be required).
4. Unzip and run AERVELYS-NEXT-Setup-0.1.0-x64.exe.
5. Sign into NEXT with the same existing CEO account.

The build is unsigned and Windows SmartScreen may warn. Review the source and the SHA256 hash in the workflow run before installing. A publicly distributed release should be code-signed.

## Local development

Requires Windows 10/11, Node.js 22, Python 3.12, plus internet for installation.

    cd desktop
    python scripts/make-icon.py
    npm install --no-audit --no-fund
    npm test
    npm run build:win

The generated installer is in desktop/dist. For development only, run npm start from the desktop folder.

## System boundaries

- The desktop shell does not contain Supabase administrative secrets.
- Auth remains inside a dedicated and persistent profile on the Windows machine.
- Only the exact NEXT HTTPS origin loads inside Electron; SimBrief, Navigraph and GitHub can open through allowlisted external system-browser links.
- No filesystem, command execution or unrestricted Electron API is exposed to remote web content.
- This first version does not automatically update. Install a new setup for newer versions.
